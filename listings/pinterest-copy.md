# Pinterest 发布手册

- **账号**：注册 Pinterest Business 账号（免费，可用 Gumroad 同邮箱）
- **Boards 建议**：`Printable Planners`、`Meal Planning`、`Productivity & Organization`
- **发布节奏**：每天 3–5 张，间隔几小时，一周内发完 18 张；之后每出新品同步发
- **链接**：pin 图里没有可点链接，发布时必须把目标 URL 填进 pin 的 "Destination link" 字段

两个产品页：
- P = https://zachmindset.gumroad.com/l/minimalist-planner-bundle
- M = https://zachmindset.gumroad.com/l/meal-planner-bundle

## 自动化备注

- Pinterest API v5 支持创建 pin（需要开发者应用 + OAuth），素材和文案都已就绪，
  拿到 token 后可写定时发布脚本（每天自动发 N 张）。
- 备选：Tailwind / Buffer 定时发布（付费工具），或手机 App 手动发（每天 10 分钟）。
